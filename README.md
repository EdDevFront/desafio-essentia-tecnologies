# TechX - Task Management Application

Desafio Técnico Full Stack para Desenvolvedor(a) na empresa TechX.

## Tecnologias Utilizadas
- **Frontend**: Angular 19, Tailwind CSS v4, TypeScript, RxJS, Signals.
- **Backend**: NestJS, TypeScript, TypeORM, MySQL, JWT Authentication, Swagger.
- **Arquitetura**: Clean Code, DDD, SOLID, KISS, DRY.

## Estutura do Projeto
- `backend/`: Aplicação REST API NestJS.
- `frontend/`: Aplicação Web Angular 19.
